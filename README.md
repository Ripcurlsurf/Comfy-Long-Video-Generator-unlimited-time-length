# 🎬 ComfyUI Long Movie Local Generator

> **Zero installation. 100% offline.** Generate production-grade, multi-scene ComfyUI workflows for feature-length video generation in seconds.

A single-file, offline HTML tool designed to build complex ComfyUI workflow JSONs for multi-scene video pipelines. Describe your scenes, configure your characters and consistency bible, and download a workflow ready to drag-and-drop straight into ComfyUI.

- ⚡ **No Node.js or Python backend required.**
- 🔒 **Runs entirely client-side** in your local browser.
- 🧱 **Subgraph packing & memory optimizations** for long multi-scene projects.
